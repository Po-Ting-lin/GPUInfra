GPUInfra class and ownership model

The current implementation separates logical frame records, a bounded best-effort GPU cache, reusable task fallback resources, and host execution. The temporary scope accepts exactly one GPU per NUMA graph copy: tasks remain GPU-bound, workers remain NUMA-bound, and cache residency never participates in scheduler selection.

StaticData

  • StaticData.h/.cpp
  • stores one fixed frame layout
  • accepts any matching incoming key without a registration list
  • resetCache() clears residency at a quiescent run boundary without freeing device buffers
  • stores no NUMA or scheduler state
  • owns one bounded GpuCacheManager
  • default cache capacity 4; capacity 0 is valid
  • owns no scheduler execution state
  • does not participate in scheduler selection
graph task instance

DummyTask

  • golden lifecycle API
  • permanent GPU binding; no host-thread binding
  • owns TaskGpuResources
  • owns private CEL, SDD, and MI objects
  • execute(FrameCpuAtom&, StaticData&)
  • acquireGpuData() validates the fixed input layout
  • uses cache hit/fill or task fallback transparently
  • exclusive checkout is owned by DummyGraph
  • not an independent thread-safe scheduling boundary
CPU frame owner

FrameCpuAtom

  • FrameCpuAtom.h/.cpp
  • owns CPU frame byte vector
  • owns intrinsic FrameMetadata
  • owns preallocated JobResult
  • frame ID, camera ID, byte count, dimensions, dtype
  • no GPU data or scheduling state
bounded cache manager

GpuCacheManager

  • GpuCacheManager.h/.cpp
  • owns fixed GpuCacheEntry[K] entries
  • owns a fixed open-addressing residency table for at most K keys
  • coordinates entry state, active accesses, empty stack, and intrusive LRU
  • average O(1) lookup and O(1) victim selection
  • selects cache hit, cache fill, or fallback
  • CUDA work runs outside its metadata mutex
fixed resident-key index

GpuResidencyTable

  • GpuResidencyTable.h/.cpp
  • preallocates at least 2K linear-probing slots
  • stores only resident/loading GpuDataKey → entry index mappings
  • average O(1) find, insert, and erase
  • backward-shift deletion; no tombstone accumulation
  • never grows, rehashes, or allocates on acquire
reusable cache entry

GpuCacheEntry

  • GpuCacheEntry.h/.cpp
  • temporarily cached complete metadata
  • directly owns GPU-keyed GpuReplica collection
  • one device buffer preallocated per entry today
  • Empty / Loading / Valid, access count, and intrusive LRU links
  • same pointer reused across LRU replacements
  • future stale-replica migration boundary

N is the number of graph-owned CPU atoms; K = gpuCacheEntries and defaults to 4. N and K are independent. DummyGraph owns phase collections, submitted flags, the ready queue, and in-flight/terminal counts. DummyTask validates the fixed layout and performs an average O(1) residency lookup; the empty stack or intrusive global LRU selects a victim in O(1) without affecting scheduler choice.

GpuDataAccess returns CacheHit, CacheFill, or TaskFallback. Cache fills and task fallback upload from immutable CPU data; cache hits skip H2D. All device buffers are allocated on the cold path and retained until their graph/task teardown.

resetCache() must run after every old-run execution finishes and before any new-run execution starts. It needs no frame list, rejects live cache/fallback leases, and performs no cudaMalloc() or cudaFree(). Between resets, one frame/camera identity must always represent the same immutable bytes.

After scheduler selection, the graph calls StaticData::execute() and DummyTask::execute(atom, staticData). One StaticData::acquireGpuData() call validates the fixed layout and resolves cache or fallback access. No incoming key must be pre-registered, and lookup never changes ready-frame, task, or worker selection.
