01

Algorithm ownership

Each DummyGraph owns one Cel, Sdd, and Mi object. No algorithm object is shared across threads.

02

Worker ownership

A loaded DummyGraph uses one manager-created slot. The context owns the slot; each algorithm owns its output buffers.

03

Hot-path contract

Initialization and parameter notification finish before frames. Execution reuses the slot and JobResult without allocation or growth.
