GPUInfra class and ownership model

The current implementation separates logical frame records, a bounded best-effort GPU cache, reusable task fallback resources, and host execution. The temporary scope accepts exactly one GPU per NUMA graph copy: tasks remain GPU-bound, workers remain NUMA-bound, and cache residency never participates in scheduler selection.

DummyGraph

  • DummyGraph.h/.cpp
  • NUMA-local worker pool
  • free DummyTask pool and FIFO frame queue
  • owns separate warmup/timed FrameCpuAtom collections
  • owns one graph-copy StaticData
  • ReadyFrame carries only an atom
  • temporarily requires exactly one eligible GPU
  • lifecycle barriers, phase gate, and cancellation
  • publishes terminal results to GraphSink
one per graph copy

StaticData

  • StaticData.h/.cpp
  • owns registered FrameMetadata[N]
  • owns one immutable frame-ID-to-FrameMetadata hash
  • stores no NUMA or scheduler state
  • owns one bounded GpuCacheManager
  • default cache capacity 4; capacity 0 is valid
  • owns no scheduler execution state
  • does not participate in scheduler selection
graph task instance

DummyTask

  • golden lifecycle API
  • permanent GPU binding; no host-thread binding
  • owns TaskGpuResources
  • owns private CEL, SDD, and MI objects
  • execute(FrameCpuAtom&, StaticData&)
  • validates input layout; acquireGpuData validates registered metadata
  • uses cache hit/fill or task fallback transparently
  • exclusive checkout is owned by DummyGraph
  • not an independent thread-safe scheduling boundary
CPU frame owner

FrameCpuAtom

  • FrameCpuAtom.h/.cpp
  • owns CPU frame byte vector
  • owns intrinsic FrameMetadata
  • owns preallocated JobResult
  • ID, byte count, dimensions, dtype
  • no GPU data or scheduling state
bounded cache manager

GpuCacheManager

  • GpuCacheManager.h/.cpp
  • owns fixed GpuCacheEntry[K] entries
  • coordinates entry state, active accesses, and LRU
  • selects cache hit, cache fill, or fallback
  • CUDA work runs outside its metadata mutex
reusable cache entry

GpuCacheEntry

  • GpuCacheEntry.h/.cpp
  • temporarily cached complete metadata
  • directly owns GPU-keyed GpuReplica collection
  • one device buffer preallocated per entry today
  • Empty / Loading / Valid, access count, and LRU
  • same pointer reused across LRU replacements
  • future stale-replica migration boundary
task CUDA lane

TaskGpuResources

  • GPU/resource/context identity

  • optional device scratch
  • non-owning GpuContext*

N is the configured frame count; K = min(gpuCacheEntries, N) and defaults to 4. DummyGraph owns phase collections, submitted flags, the ready queue, and in-flight/terminal counts. DummyTask performs an average O(1) registered-metadata lookup, then the cache scans its small fixed entry array without affecting scheduler choice.

GpuDataAccess returns CacheHit, CacheFill, or TaskFallback. Cache fills and task fallback upload from immutable CPU data; cache hits skip H2D. All device buffers are allocated on the cold path and retained until their graph/task teardown.

After scheduler selection, the graph calls StaticData::execute() and DummyTask::execute(atom, staticData). One StaticData::acquireGpuData() call validates registered metadata and resolves cache or fallback access. Neither lookup changes ready-frame, task, or worker selection.
