GPUInfra class and ownership model

The current implementation separates logical frame data, reusable task resources, and host execution. A task is GPU-bound but can move between all graph threads in its NUMA-node graph copy.

DummyGraph

  • NUMA-local worker pool

  • warmup/timed FrameSlot collections
  • lifecycle barriers, phase gate, and cancellation
  • publishes terminal results to GraphSink

DummyTask

  • owns private CEL, SDD, and MI objects
  • atomic single-execution guard

  • preallocated JobResult
