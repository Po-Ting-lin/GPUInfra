Resource invariants

Frame is movableA slot can use whichever local-GPU task becomes free. It owns no CUDA allocation.
Task is reusableA task keeps its GPU lane but can run sequentially on different host threads.
Thread is temporaryA worker owns only CPU affinity and one active call, never task or frame state.
Hot path is fixedNo allocation, vector growth, manager mutex, or device-wide synchronization.
Lifecycle is copy-wideAll tasks load, register, and notify before any frame begins.
Failure is globalOne graph error cancels queued work across all NUMA copies and suppresses timing.
