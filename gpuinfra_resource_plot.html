GPUInfra resource topology

Illustrative temporary deployment. Each GPU-bearing NUMA node gets one graph copy with exactly one eligible GPU. Registered frame metadata is independent from a small best-effort GPU cache, graph collections own execution state, and every task has a persistent correctness fallback.

An empty or inactive LRU entry yields CacheFill. Capacity zero, a matching entry still loading, or all active entries yields TaskFallback immediately. Both buffers already exist, so the hot path performs no cudaMalloc() or cudaFree().

Resource invariants

Graph owns execution statePhase collections, submitted flags, ready queue, and counters remain independent from GPU residency.
Cache is boundedFrameSlot[K] uses inactive-entry LRU; K defaults to 4 and may be zero.
CPU input reconstructsFrameCpuAtom owns immutable bytes used by every fill or fallback H2D.
Active entries are safeReader/fill leases prevent eviction; incomplete fills return to Empty.
Task fallback is persistentEach TaskGpuResources owns one d_input allocated in load and freed in unload.
Task is graph-guardedDummyGraph removes it from freeTasks for the whole execute call; the task owns no atomic scheduling guard.
Thread is temporaryA worker owns only CPU affinity and one active call, never task or frame state.
Hot path is fixedNo allocation, vector growth, manager mutex, or device-wide synchronization.
Topology is explicitZero or multiple GPUs in one graph copy fail initialization until replica migration is implemented.
Future extension is internalA second GPU adds preallocated replicas and lazy migration inside cache access, not GPU-aware scheduling.
